# Сервис управления рассылками (Mailing Service)

Веб-приложение на Django для управления рассылками сообщений клиентам.

## 🚀 Функциональность

### Часть 1: Разработка сервиса
- **Управление клиентами**: создание, просмотр, редактирование и удаление получателей (Email, Ф.И.О., Комментарий).
- **Управление сообщениями**: создание, просмотр, редактирование и удаление сообщений (Тема, Тело письма).
- **Управление рассылками**: создание, просмотр, редактирование и удаление рассылок (Дата начала, Дата окончания, Статус, Сообщение, Получатели).
- **Динамический статус**: статус рассылки («Создана», «Запущена», «Завершена») пересчитывается автоматически.
- **Отправка по требованию**: ручной запуск рассылки с проверкой временного диапазона.
- **История попыток**: сохранение статуса каждой попытки отправки (Успешно / Не успешно, время, ответ сервера) через `bulk_create`.
- **Главная страница**: сводная статистика (всего рассылок, активных рассылок, уникальных получателей).

### Часть 2: Расширение функциональности
- **Аутентификация**: кастомная модель пользователя (вход по Email), регистрация, вход, выход.
- **Роли и права**:
  - *Пользователь* — управляет только своими клиентами и рассылками.
  - *Менеджер* — видит всех клиентов и рассылки, может блокировать пользователей и отключать рассылки.
- **Статистика**: отдельная страница для каждой рассылки (всего отправлено, успешно, ошибки).
- **Кеширование**: серверное кеширование главной страницы на 15 минут для снижения нагрузки на БД.

## 🛠 Стек технологий
- Python 3.13
- Django 6.1
- SQLite (база данных)
- Bootstrap 5 (интерфейс)
- Poetry (управление зависимостями)

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
   git clone <url_репозитория>
   cd mailing_service

2. Установите зависимости:
   poetry install

3. Примените миграции:
   poetry run python manage.py migrate

4. Создайте суперпользователя (или используйте существующего):
   poetry run python manage.py createsuperuser

5. Запустите сервер:
   poetry run python manage.py runserver

6. Перейдите в браузере:
    Главная: http://127.0.0.1:8000/mailings/
    Админка: http://127.0.0.1:8000/admin/
